# 🏠 House Price Prediction

A Machine Learning project that predicts house prices based on different property features such as area, bedrooms, bathrooms, stories, parking, location-related facilities, and furnishing status.

The project uses **Linear Regression** to learn the relationship between house features and their prices.

A simple and interactive **Streamlit web application** is also created to allow users to enter house details and get an estimated house price.

## 📌 Project Purpose

The main purpose of this project is to understand and implement the complete Machine Learning workflow:

- Loading a dataset
- Understanding and inspecting data
- Data cleaning
- Exploratory Data Analysis (EDA)
- Feature engineering
- Encoding categorical data
- Splitting data into training and testing sets
- Training a Machine Learning model
- Making predictions
- Evaluating model performance
- Saving the trained model
- Building a simple user interface
- Deploying the application

---

# 🎯 Problem Statement

House prices depend on several factors such as:

- Area of the house
- Number of bedrooms
- Number of bathrooms
- Number of stories
- Parking availability
- Main road access
- Guest room
- Basement
- Air conditioning
- Hot water heating
- Preferred location
- Furnishing status

The goal of this project is to use these features to predict the expected price of a house.
